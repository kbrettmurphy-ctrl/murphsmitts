# MurphOS Roadmap

MurphOS is the internal admin and workflow system for Murph’s Mitts.

The goal is to make the admin portal feel like a purpose-built glove repair operating system, not a generic order database.

## Guiding Principles

- Workflow first, database second.
- The Orders list should handle most daily processing.
- Full order detail exists for exceptions and deeper editing.
- Do not add features Brett will not use regularly.
- Keep the public website separate from admin tooling.
- Preserve existing order email/SMS automation unless deliberately changing it.
- Build in sprints.
- Do not implement future sprint ideas early.

## Sprint Order

1. Workflow Orders
2. Dashboard
3. Map
4. Customer Profiles
5. Workbench Mode
6. Inventory Intelligence
7. Analytics
8. Polish
